Page Turn Animation

A KOReader plugin that adds a visual animation when turning pages, making page transitions smoother and more dynamic.

Features

- Animation when turning pages forward and backward.
- Different animation directions.
- Configurable animation speed.
- Configurable number of animation steps.
- Independent settings for forward and backward page turns.
- Support for normal and night mode.
- Designed to minimize performance impact and keep page turning responsive.

Configuration

The plugin provides settings to customize the animation, speed, direction, and other parameters according to your preferences.

Configuration can be accessed from:

Tools → More tools → Page Turn Animation

Installation

Copy the "page_turn_animation.koplugin" folder into the KOReader "plugins" directory and restart KOReader.

Compatibility

Designed to work with formats supported by KOReader.
